# Xplorer

App Android personnelle de conseils crypto : quand acheter, quand attendre, quand vendre, pourquoi et combien.

- Lecture seule de Coinbase (clé ECDSA, permission « View ») : soldes, achats et ventes sur les graphiques.
- Aucun ordre n'est jamais passé par l'app.
- Prix : CoinGecko, avec Coinbase en secours.
- Règle GEOD : achat seulement, vente proposée à partir de x20 du prix d'achat.

L'APK est compilé automatiquement à chaque mise à jour (onglet Releases).
Dernière version : https://github.com/maikel-maker/Xplorer/releases/latest/download/Xplorer.apk
